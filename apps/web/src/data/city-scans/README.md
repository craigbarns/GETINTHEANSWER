# City scans

Real engine answers, one file per `<industry>__<city>.json`, generated by
`scripts/generate_city_scans.py`.

A pair with a file here renders its measured block on
`/ai-seo-for/<industry>/<city>` and enters the sitemap. A pair without one is
`noindex`: without measured data the page is the industry template with the
city name swapped in, which is what got these pages indexed around position 79
with zero clicks.

Regenerate periodically — the answers move.
